# 雷达体扫三维显示与分析系统

浏览器内运行的天气雷达体扫三维显示与分析工作台。TypeScript + WebGL2，体渲染着色器手写，重采样在 Web Worker 中完成，数据存 IndexedDB，全程本地处理、不上传任何数据。

## 运行

```bash
pnpm install
pnpm dev          # 开发服务器
pnpm build        # 类型检查 + 生产构建
pnpm gen-data     # 生成 RVF 合成样本到 sample_data/
```

无任何运行时第三方依赖，仅 Vite/TypeScript/tsx 三个开发依赖。

## 七个页面

| 页面 | 能力 |
| --- | --- |
| 数据管理 | 导入 RVF、按站号/时间排序、缺仰角标黄提示且不影响其他仰角、一键合成测试数据 |
| PPI / RHI | 反射率/径向速度/谱宽标准色标，仰角切换、速度自动退模糊、静态杂波剔除、真 RHI 距离-高度剖面 |
| 三维体渲染 | Worker 重采样笛卡尔网格，光线步进体渲染与等值面双模式，地形与城市边界叠加，轨道相机 |
| 剖面分析 | 缩略 PPI 上拖拽任意剖面线，三维场景生成垂直切面，观察悬垂与 BWER |
| 产品计算 | 组合反射率 CR、回波顶高 ET（18.3dBZ）、垂直积分液态水 VIL，PNG/CSV 导出 |
| 动画回放 | 连续体扫 CR 动画，45dBZ 阈值连通域识别单体，最近邻匹配追踪轨迹 |
| 设置与自检 | 格距/叠加开关设置，内置两条验收标准的自动化自检 |

## 关键技术

### 波束几何与重采样

- 4/3 等效地球半径模型，斜距/仰角/方位到雷达中心笛卡尔坐标的精确换算，含地球曲率与标准大气折射修正
- Worker 内 splat 到规则笛卡尔网格（默认 200m 格距，±60km 水平范围，15km 高度），同格点取最大反射率
- 两轮 6 邻域填缝，仅填充被有效格点半包围的空洞
- 结果通过 Transferable 零拷贝回主线程

### 三维渲染

- R8 三维纹理 + 全屏光线步进，前向 alpha 积分做体渲染
- 等值面模式在同一着色器内做阈值穿越检测，中心差分求梯度法线，无 Marching Cubes 查表
- 地形按合成高度场起伏，城市边界为线框叠加

### 速度退模糊

极坐标区域生长 BFS：反射率最强库播种，多连通区独立生长，仅当相邻原始跳变超过 Nyquist 时按 2 倍 Nyquist 整数倍选择最小跳变订正量。

### 回波核心定位（验收用）

取每个真值核心附近反射率最强的单个波束样本位置作为核心定位。该定义与雷达业务"峰值核心"一致，精度只取决于波束几何（库长 250m、方位 1°），不受笛卡尔网格格距量化影响。

## 验收标准

在「设置与自检」页一键运行：

1. **位置误差 < 200m**：合成超级单体会输出解析意义上的峰值真值，与重采样后波束级峰值定位比对
2. **端到端 < 3s**：20 仰角体扫从入库/读取、RVF 解码到 Worker 重采样与产品计算的总耗时，分项计时展示

Node 侧等价校验脚本：

```bash
npx tsx scripts/validate_core.ts        # 位置误差、重采样性能、产品有效性
npx tsx scripts/validate_algorithms.ts  # 退模糊、缺仰角容错、单体追踪
```

## RVF 二进制格式

自定义小端格式：128 字节文件头（站号、时间、仰角目录计数、量程、Nyquist 等）+ 每仰角 32 字节目录 + 逐射线数据（8 字节头 + 三场 u8 量化库值）。反射率 0.5dBZ 步进，速度 0.5m/s 步进，谱宽 0.125m/s 步进，255 表示缺测。

## 目录结构

```

  workers/   重采样 Worker（网格 + CR/ET/VIL + 核心定位）
  webgl/     GL 工具、PPI/RHI/体渲染/剖面/产品/地形渲染器、轨道相机
  pages/     七个路由页面
  services/  流水线、数据与杂波服务
  ui/        设计 token、组件、Toast、图例
scripts/     合成数据导出与数值校验
```
